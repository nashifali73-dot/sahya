# Hero video

Put the hero background video here:

- `hero.mp4`: 16:9, 1920×1080, 8–10 s seamless loop, H.264, no audio, under 5 MB (used on desktop, and on mobile if there is no mobile file)
- `hero-mobile.mp4` (optional): 9:16, 1080×1920, under 3 MB

The site fades the video in over the hero photo as soon as it can play. If the file is missing, the photo stays.
